Conectar el Claude de José con el n8n de GOT

  1. n8n (con el usuario de José): Settings → n8n API → Create an API key. Copiarla, porque solo se ve una vez.
  2. Node.js: abrir PowerShell y escribir node -v. Si no responde, instalar la versión LTS de nodejs.org.
  3. Claude Desktop: Ajustes → Desarrollador → Editar configuración. Pegar esto, poniendo vuestra dirección de n8n y la clave del paso 1:
{
  "mcpServers": {
    "n8n-mcp": {
      "command": "cmd",
      "args": ["/c", "npx", "-y", "n8n-mcp"],
      "env": {
        "MCP_MODE": "stdio",
        "LOG_LEVEL": "error",
        "DISABLE_CONSOLE_OUTPUT": "true",
        "N8N_API_URL": "https://DIRECCION-DE-VUESTRO-N8N:PUERTO",
        "N8N_API_KEY": "PEGAR-AQUI-LA-CLAVE"
      }
    }
  }
}
  1. Cerrar Claude Desktop del todo (también el icono junto al reloj) y volver a abrirlo.
  2. Probar en un chat: «Lista mis flujos de n8n».

Si el certificado es autofirmado y sale el error self-signed certificate, añadir dentro de env:

"NODE_EXTRA_CA_CERTS": "C:\\ruta\\al\\certificado.pem"

Esto funciona en Claude Desktop o en Claude Code. En Conectores de claude.ai no: su n8n está en la red de la oficina y desde fuera no se alcanza.
