REA (Reverse Engineer Anything)

morluto/rea

Conecta tu agente de IA con herramientas de ingeniería inversa para que te explique cómo funciona una app sin tener su código fuente.

Para quién: desarrolladores y makers que trabajan con Claude Code, Codex, Cursor o Gemini CLI y quieren entender cómo está hecha una función de otra app antes de construir algo parecido. Analiza binarios nativos, apps JavaScript y Electron, ensamblados .NET y webs, y lo hace en tu ordenador.

  • 78.562estrellas en la semana del 25-oct-2026
  • 380.020estrellas totales a esa fecha
  • TypeScriptlenguaje
  • MITlicencia

Instalación

npx rea-agents setup

Pide Node.js 22 (22.23.4 o posterior), 24 (24.22.1 o posterior) o 26.12.1 en adelante, con npm. El asistente te pregunta con qué agentes lo vas a usar, te enseña los cambios en su configuración y los aplica cuando das el visto bueno. Luego reinicias el agente.

Abrir el repo oficial

Úsalo con cabeza. Solo con software tuyo o que tengas permiso para analizar; el propio proyecto lo deja escrito. Y bájalo únicamente de sus fuentes oficiales: github.com/morluto/rea, rea.tools o el paquete rea-agents de npm. El README avisa de que circulan copias con nombres parecidos.

security-audit (Cloudflare)

cloudflare/security-audit-skill

Una skill que convierte a tu agente de programación en auditor de seguridad: revisa tu código en seis fases y cada hallazgo lo verifica otro agente distinto.

Para quién: devs y equipos pequeños que mantienen código propio (webs, APIs, apps) y no tienen a nadie de seguridad en plantilla. Según el README, es la skill de la que salió el sistema de búsqueda de vulnerabilidades de Cloudflare. Cada hallazgo acaba marcado como confirmed, needs_validation o rejected, y al final te deja un REPORT.md con el resumen.

  • 12.680estrellas en la semana del 25-oct-2026
  • 45.196estrellas totales a esa fecha
  • JavaScriptlenguaje
  • MITlicencia

Instalación

npx skills add https://github.com/cloudflare/security-audit-skill \
  --skill security-audit
Abrir el repo oficial

Y para lanzarla, dentro del proyecto le dices a tu agente

security audit this codebase
Leer el post de Cloudflare

Lo que no es. Es una primera revisión guiada. No sustituye a una auditoría profesional ni te garantiza que no quede ningún fallo: lo que marque como confirmado, revísalo antes de dar nada por cerrado.

Orca

stablyai/orca

Un orquestador de agentes de programación: lanza Codex, Claude Code, OpenCode o Pi en paralelo, cada uno en su propio worktree, y los sigues desde una sola app.

Para quién: quien ya programa con agentes y quiere repartir el mismo encargo entre varios, comparar lo que sale y fusionar el mejor. Hay app de escritorio para macOS, Windows y Linux, y otra para el móvil (iOS y Android) que te avisa cuando un agente termina. Usas cada agente con tu propia suscripción.

GH · 4

graphify

Graphify-Labs/graphify

Convierte tu proyecto (código, documentación, esquemas SQL, configuraciones y PDF) en un grafo de conocimiento que tu asistente de IA consulta en vez de leer archivo por archivo.

Para quién: quien hereda código o trabaja en proyectos grandes y quiere que su asistente entienda la estructura sin releerlo todo. El código lo analiza en local con tree-sitter, sin pasar por ningún modelo. Te deja tres archivos: graph.html (el mapa navegable), GRAPH_REPORT.md (conceptos clave y preguntas sugeridas) y graph.json.

  • 6.868estrellas en la semana del 25-oct-2026
  • 134.585estrellas totales a esa fecha
  • Pythonlenguaje
  • Apache-2.0licencia

Instalación (Python 3.10 o superior)

uv tool install graphifyy
graphify install

Después abres tu asistente dentro del proyecto y escribes /graphify .. Si no usas uv, el README da como alternativa pipx install graphifyy.

Abrir el repo oficial

Ojo con el nombre. El paquete oficial es graphifyy, con dos «y». El README avisa de que el resto de paquetes graphify* de PyPI no tienen nada que ver con ellos. Aparte del repo abierto tienen una versión de pago, Graphify Cloud; esta ficha habla solo del open source.

OpenCode

anomalyco/opencode

Un agente de programación con IA de código abierto que funciona en la terminal y también como app de escritorio, todavía en beta.

Para quién: devs que quieren una alternativa abierta a los agentes cerrados. Trae dos agentes que se cambian con la tecla Tab: build, con acceso completo, y plan, de solo lectura, que no edita archivos y te pide permiso antes de ejecutar un comando. Este último viene muy bien para explorar un código que no conoces sin romper nada.

Instalación

curl -fsSL https://opencode.ai/v2/install | bash

Si prefieres npm: npm i -g @opencode/cli@latest. La app de escritorio se baja de opencode.ai/download.

HyperFrames (HeyGen)

heygen-com/hyperframes

El framework abierto de HeyGen que convierte HTML, CSS, multimedia y animaciones en vídeos MP4, pensado para que lo use tu agente de IA.

Para quién: creadores, marketers y devs que quieren sacar una intro o un gráfico animado pidiéndoselo al agente. El README pone de ejemplo una intro de producto de diez segundos con título en fundido, vídeo de fondo y música suave. Necesitas Node.js 22 o superior y FFmpeg.

ComfyUI

Comfy-Org/ComfyUI

Interfaz, API y motor por nodos para modelos de difusión: genera imágenes, vídeo, 3D y audio con IA en tu ordenador o en su nube.

Para quién: creativos, diseñadores y creadores de contenido que quieren controlar cada paso de la generación. Cada nodo es un paso y los vas conectando. Según su README, puede mover modelos abiertos grandes con solo 4 GB de VRAM y 8 GB de RAM; la cifra es suya y yo no la he medido. Con los partner nodes llegas también a modelos cerrados como Nano Banana o Seedance.

Instalación

En Windows y Mac lo que recomiendan es la app de escritorio: comfy.org/download. Por terminal, con su CLI:

pip install comfy-cli
comfy install
